# design-reconstruction skill

*Reference for users of the game-designer plugin: what the `design-reconstruction` skill covers and produces.*

| Field | Value |
|---|---|
| Name | `design-reconstruction` |
| File | `skills/design-reconstruction/SKILL.md` |
| Trigger | Use when remaking, porting or matching an existing game and its rules, numbers, levels and feel must be reconstructed faithfully from public observation (footage, manuals, guides, play), with every claim sourced. |
| Covers | Rebuild an existing game's design from observation with an evidence ladder, frame counts and certainty tags, copying no expression. |

## Inputs

- Reference title, version and platform
- Public sources

## Outputs

- Observation log per system
- Reconstructed rules spec with evidence IDs
- Deviations list

## Supporting files

- [`observation-log.md`](../../skills/design-reconstruction/observation-log.md): sources table, observations table, status per rule

## Terms and values

- Evidence levels 1 (own controlled observation) to 5 (recollection, forums)
- Confirmed: two independent level 1-3 sources, or a repeated level-1 observation

## Documentation owed

Reference (spec, evidence log, sources); explanation (deviations).
