# playtesting skill

*Reference for users of the game-designer plugin: what the `playtesting` skill covers and produces.*

| Field | Value |
|---|---|
| Name | `playtesting` |
| File | `skills/playtesting/SKILL.md` |
| Trigger | Use when planning, running or analysing a playtest, turning player observations and telemetry into design changes, or deciding whether a change worked. |
| Covers | Question-led playtests: method choice, recruiting, neutral facilitation, synthesis by severity, RITE iteration. |

## Inputs

- Questions tied to experience goals
- A runnable build
- Players from the target audience

## Outputs

- Playtest plan and script
- One-page report: issues by severity, frequency, goal impact; decisions; predictions

## Terms and values

- Severity: blocks progress / frustration or misunderstanding / minor friction

## Documentation owed

Reference (dated playtest report); reference and explanation updates for resulting changes; how-to (test protocol).
