# game-feel skill

*Reference for users of the game-designer plugin: what the `game-feel` skill covers and produces.*

| Field | Value |
|---|---|
| Name | `game-feel` |
| File | `skills/game-feel/SKILL.md` |
| Trigger | Use when defining, measuring or reviewing how controls and feedback feel (responsiveness, weight, impact, readability), or when matching the feel of a reference game. |
| Covers | Feel as measurable targets across physicality, amplification and support; perception thresholds; frame-count measurement. |

## Inputs

- Target feeling and experience goal
- Player actions and game events

## Outputs

- Feel table per action
- Numeric deltas from build measurement

## Supporting files

- [`feel-table.md`](../../skills/game-feel/feel-table.md): table columns, feedback tiers 1-4, footage measurement method

## Terms and values

- Response under about 100 ms reads as instantaneous
