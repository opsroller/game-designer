# level-design skill

*Reference for users of the game-designer plugin: what the `level-design` skill covers and produces.*

| Field | Value |
|---|---|
| Name | `level-design` |
| File | `skills/level-design/SKILL.md` |
| Trigger | Use when designing levels, maps, encounters, worlds or a progression of content, and when ordering when mechanics are introduced and how difficulty and intensity rise. |
| Covers | Progression order of ideas, the introduce/develop/twist/combine arc, difficulty levers, level briefs, levels as data. |

## Inputs

- List of mechanics and content ideas
- Level data format from the project profile
- Difficulty targets

## Outputs

- Progression table: unit, idea, levers, target success rate
- Level brief per level
- Level data files with fixed seeds

## Documentation owed

Reference (progression table, level format); explanation (why this order); how-to ("How to add a level").

To build a unit from a finished brief, run the [author-level workflow](workflow-author-level.md).
