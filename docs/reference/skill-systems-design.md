# systems-design skill

*Reference for users of the game-designer plugin: what the `systems-design` skill covers and produces.*

| Field | Value |
|---|---|
| Name | `systems-design` |
| File | `skills/systems-design/SKILL.md` |
| Trigger | Use when designing or reworking a game's core loop, mechanics or interlocking systems from an intended player experience, or when diagnosing why a system produces the wrong behaviour. |
| Covers | Design from experience goals inward using MDA, loops and arcs, resource maps and feedback loops. |

## Inputs

- Experience goals or pillars
- Constraints: platform, session length, audience, scope

## Outputs

- Problem statement
- Core and outer loop diagram
- Resource map: sources, sinks, converters, traders, pools
- Feedback loops with intended direction and strength
- Degenerate strategies and counters

## Documentation owed

Reference (rules via design-spec); explanation ("About <system> design").
