# Rules spec

- One document, organised by system (board, moves, scoring, goals,
  powers, structure). Every rule states its numbers and edge cases.
- Mark unknowns **[verify]**; settle each from two independent public
  sources (gameplay video with timestamps, walkthroughs, reviews, store
  listings). Record observations in your own words, cite sources.
- If sources disagree or none exist, pick the more playable option, mark
  it **[chosen]** with a one-line reason, move on.
- Tell the gameplay programmer whenever a rule changes a code-relevant
  number.
