# Balance simulation

- Run the project's simulator (or ask for one) with several bot
  strategies, from naive to goal-aware, many runs per level and
  difficulty.
- Track win rate and margin (time or moves left) per level; plot the
  curve across an episode. It should rise smoothly, with small rests
  after spikes.
- Agree targets per difficulty before tuning; record them in the
  project's design docs, and put the sim summary in each content PR.
