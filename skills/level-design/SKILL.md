# Level design

- Levels are data files in the project's level format; one file per
  level, a fixed seed for repeatable testing.
- Each episode or world introduces one new idea (mechanic, power,
  obstacle) and lets the player practise it before combining.
- Raise difficulty with goal size and variety first, time pressure
  second.
- Keep a short README per episode stating its idea and intended curve.
