# Game feel

- Express feel as measurable targets: input-to-response time, animation
  durations, easing, gaps between chained events, audio cues per event.
- When remaking a game, measure the reference from video frame times.
- Readability beats spectacle: the player must always see the state.
- Review builds against the targets and file concrete deltas ("swap
  0.22 s, target 0.14 s").
